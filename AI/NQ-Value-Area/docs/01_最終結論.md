# 最終結論：NQ 1口、+$1,100 止盈／−$2,900 止損、開盤後3小時

更新：2026-10-24。研究用，不是投資建議；不會自動下單。

---

## 一句話
測了 **超過1,000種規則組合、20多種指標**，**沒有任何一種通過「事先寫好的穩健性檢查」**。所以目前**不能說有哪一種方法「確定」讓賺錢機率更高**。有 2 個值得繼續追的線索，下一步要用 2026-10-20 以後的新資料做紙上測試，才能判斷是真是假。

## 1. 這個題目的數學（最重要）
| 項目 | 數字 |
|---|---|
| 止盈／止損 | 55點／145點（每點$20） |
| 扣成本後的損益兩平勝率 | **73.7%** |
| 完全隨機進場的勝率 | 約 **72.5%**（扣成本後仍小虧） |
| 開盤後3小時振幅中位數 | 222點 |

- 勝率 70% 多是這個結構「天生」的，**看勝率沒有意義，要看扣成本後的期望值**。
- 一次止損要連賺約 **3 次**才賺回來。
- 「卡住」是重要虧損來源：到 12:29 都沒碰到止盈或停損的單，平均每筆虧 $500～$700。（2026-10-26 更正：對 I2 來說，止損 14 筆合計 −$41,272，比卡住 48 筆合計 −$32,204 更多，兩者都是主要來源。）

- 三年合併的 95% 信賴區間：I2 為 −$32～+$377，突破共振為 −$19～+$221，**都還包含0**。

## 3. 指標：哪些有用？
- 測了 VWAP（距離、斜率、偏離σ）、MACD、RSI、EMA9／21、布林%b、ADX、ATR、開盤區間位置、前日與隔夜高低、是否掃過高低點、動能、相對成交量、NQ／ES強弱與SMT背離、時間、跳空、波動狀態——共74組「指標×方向」。
- **2024年找到的規律，到2025年仍成立的：0組。**
- 把所有指標合成機率模型：2025 每筆 **−$39**；2026 每筆 +$36，**還輸給「一律做多」的 +$90**。
- 結論：**單看這些指標，不能提高先碰+$1,100的機率。** 有用的不是指標本身，而是「價位結構」（前日價值區、開盤區間）。

## 5. 那要怎麼賺錢？我的建議
1. **停止在舊資料上繼續挖。** 2024～2026 每一段都已經被看過很多次，再挖只會找到「剛好符合過去」的規則。
2. **紙上前進測試兩個線索**：I2 前日價值區80%法則、突破共振。規則現在就凍結，不再修改。
   - 每天開盤前我先算好 I2 的價值區上下緣，開盤後照規則標註訊號。
   - **2026-10-26 更新**：改為**只交易 I2 v1**（每天最多一筆；共振、v2 只紙上紀錄），驗收改成第 40／80／160 筆固定評估、三種結論（支持／否定／證據不足），「40 筆為正」不再是上真倉的依據。見 研究程式（未公開） 與 前進測試紀錄（未公開）。
   - 停止標準（風控，和研究結論分開）：連續 3 次止損、累計 ≤ −$8,700，或第 20 筆期望值 < −$300。
3. **實盤**：驗收結論為「支持」、而且即時行情與下單流程驗證完成前，不開真倉。通過後先 1 口；**不要多個帳戶同時跑同一個訊號**（一次止損就會成倍放大）。
4. **最大的槓桿其實是止盈止損結構本身**：+$1,100／−$2,900 要求勝率 73.7% 以上，本身就很難。如果願意，下一輪可以在不改進場規則的前提下，比較其他結構（例如 +$1,100／−$1,100、或加上時間限制），看哪一種讓同樣的訊號期望值更高。這會改變原本的規則，所以由交易者決定。

# 交易邏輯設計 v1：NQ 1口，每天一筆，+$1,100 止盈／−$2,900 止損

研究用，不是投資建議。文件與指標只供研究，不會自動下單。
狀態：**假設，尚未驗證**。

---

## 0. 先搞懂這個題目的數學

| 項目 | 數字 |
|---|---|
| 1口NQ每點 | $20 |
| 止盈 $1,100 | 55 點 |
| 止損 $2,900 | 145 點 |
| 扣成本後損益兩平勝率 | **73.7%**（stress成本） |
| 完全隨機進場，先碰止盈的機率 | **72.5%** |
| 開盤後3小時振幅中位數 | 222 點（25%分位 158、75%分位 310） |

**結論**：隨便進場勝率就有七成多，但還是小虧。要賺錢，勝率至少要做到 **78–80%**，才扛得住成本和偶爾的跳空停損。
**最大的敵人不是停損，是「卡住」**：前幾輪回測中，到 12:29 都沒碰到止盈或停損的單，平均每筆虧 $476～$700。

## 1. 整套邏輯分五層（每一層都要能回答「為什麼」）

### 第一層：今天要不要做？（日過濾）
- 只在波動夠的日子做：過去20日平均振幅（ATR20）不能太低，否則55點常常到不了、變成卡住的單。
- 開盤位置：開盤在前一日高低範圍**外**＝較可能是趨勢日；在範圍**內**＝較可能是區間日。兩種日子用不同的策略（見第二層）。目前回測線索：通道突破在「範圍外」的日子明顯較好（未驗證）。
- 避開開盤後頭5分鐘（09:30–09:35）亂流；不在 10:00 整點前後2分鐘進場（常有經濟數據）。

### 第二層：在哪裡進場？（位置）
四種候選情境，每天只取第一個成立的：

| 代號 | 情境 | 白話 |
|---|---|---|
| S1 | **多次支撐反彈**（原始範例1） | 開盤半小時後，價格跌到「前5天被測試過至少2次且都彈起來」的價位區，同時是今天新低，出現止跌訊號才做多 |
| S2 | **急跌後反彈**（原始範例2） | 從開盤或今日高點跌超過「0.5／0.75／1倍 ATR20」（500點太少見，3年只有13天），出現第一個反彈確認才做多 |
| S3 | **趨勢日回調**（我加的） | 開盤在前日範圍外、且開盤30分鐘順著同方向走，等第一次回到 VWAP 或 EMA21 附近並止跌，順勢進場 |
| S4 | **掃流動性後收回**（ICT概念） | 價格刺穿前日低點或隔夜低點（或高點），15分鐘內又收回，朝收回方向進場 |

S1、S2 也測「反向做空」的鏡像版本，確認不是只靠 NQ 這幾年一直漲。

### 第三層：什麼時候扣扳機？（觸發）
- 不在價格往下掉的過程中接刀；一定要等**已收完的K棒**確認：
  - 1分鐘收盤回到支撐上方，或
  - 1分鐘收盤突破前3根高點（「一有反彈」的具體定義），或
  - 5分鐘收盤收回。
- 訊號在K棒收盤確認，下一根開盤才進場。

### 第四層：進場後怎麼管？（出場管理）
- 基本：+55點止盈、−145點止損、12:29 前未結束就出場。
- **原始範例「浮盈超過$200，就把停損移到+$50」**，一起測多種版本：

| 啟動條件（浮盈） | 移動後的停損 |
|---|---|
| +$200（10點） | 保本、+$50 |
| +$400（20點） | 保本、+$50、+$200 |
| +$600（30點） | 保本、+$50、+$200 |

  這會把一些原本 −$2,900 的單變成小賺，勝率會上升；但也會把一些原本會打到+$1,100的單提早洗出場。**要看的是期望值，不是勝率。**
- 啟動後的新停損，從下一根K棒才生效（同一根K棒內先後順序不知道，用保守算法）。

### 第五層：什麼時候停手？（風控）
- 每天最多一筆；止損後當天不再做（不報復性交易）。
- 連續2天止損，第3天只觀察不下單（回測會另外算這條規則對回撤的影響）。
- 報告一定列出：1口NQ的最大回撤、最長連虧、最差連續20筆。這套 +$1,100／−$2,900 的結構，**一次止損要連賺約3次才回本**。

## 2. 怎麼確定「賺錢機率更高」是真的
1. 每個情境都和「同一天、同一時間隨機做多或做空」以及「同一天隨機時間做多」比，要明顯贏過才算。
2. 2024、2025、2026-01～07 **三段都要扣成本後賺錢**，而且每段至少30筆。
3. ES 用同樣邏輯也要不虧。
4. 一共會測約300種組合，單靠運氣就會有好幾組看起來很好；報告會寫出「純靠運氣預期會有幾組過關」。
5. 通過的候選，最後要用 **2026-10-20 以後的新資料做紙上前進測試**，這才是真正沒看過的資料。

## 2.55 目前的實證結論（2026-10-24，第12步）
- **最好的線索：I2 前日價值區80%法則。** 做法：
  1. 開盤前：用前一個交易日（同合約）美股盤中 09:30–16:00 的成交量，算出成交量最密集、涵蓋70%成交量的價格區（價值區，上緣 VAH、下緣 VAL）。
  2. 09:30 開盤價在 VAH 之上 → 準備做空；在 VAL 之下 → 準備做多；在區內 → 今天不做 I2。
  3. 價格回到價值區內，連續 2 根 5 分K 收在區內 → 下一分鐘開盤進場，往區的另一邊做。
  4. 09:35–11:30 之間才進場，避開 09:58–10:02。
  5. +55點止盈、−145點止損，12:29 還沒結束就出場。
  - 回測：2026 勝率81%、每筆+$409（43筆）；2024、2025 每筆約+$95。**尚未證明穩健**，正在做第13步檢查。
- **不要用「浮盈$200移停損到+$50」**：勝率升高但期望值下降。
- **I3 SMT背離不要用**：三年都虧。
- 多訊號共振（I5）三年都小賺、筆數多，可當作第二條候選規則。


## 3. 兩個原始範例的提醒
- **範例1**：「確保這個位置可以」在事前沒辦法確保，只能用「過去被測試幾次、彈多少」來量化。量化的定義寫在規格裡，回測會告訴我們這種支撐的實際勝率。
- **範例2**：500點太少見（2024年0次、2025年3次、2026年1–7月10次），統計上無法判斷，所以改用相對波動的跌幅，並同時列出絕對300／500點的筆數供參考。

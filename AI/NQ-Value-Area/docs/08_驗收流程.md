# 驗收流程（2026-10-26 登記，取代舊的「40 筆合格」作為上線依據）

研究用，不是投資建議；不會自動下單。
依據：研究結論與外部審查（見 10_外部審查摘要.md）。
本文件登記後不再修改；要改就另開新版本，並從新版本登記日重新起算。

## 1. 唯一主要候選
- **I2 v1**（`I2|5m_width0`，研究程式（未公開））是唯一可能進入真倉的規則。
- **每天最多交易一筆，就是 I2 v1 的那一筆**。I2 v1 當天沒有訊號就不交易，**不改做其他規則**。
- 突破共振 v1、v2 I2、v2 突破共振：繼續紙上紀錄，作為次要對照，**不做上線決策**。
- 規則本身（進場、止盈 +55、止損 −145、12:29 出場）完全不變。

## 2. 正式計數起點
- 正式驗收樣本從 **2026-10-26（含）** 的 I2 v1 交易起算（本文件登記之後）。
- 2026-10-20～10-23 的 3 筆列為「凍結後第一批」：檔案時間戳顯示凍結（10/24 13:24）早於取得這幾天的資料（10/24 14:06），但不納入正式驗收樣本，只另外列示。

## 3. 固定評估時點與三種結論
只在正式樣本達到 **40、80、160 筆**時評估；其他時候只看、不下結論。
令每筆淨損益（stress 成本）的平均為 m、t = m ÷（標準差 ÷ √n）。I2 v1 每天最多一筆，所以「筆」就是「交易日」。

| 時點 | 支持（兩項都要成立） | 否定 | 其他 |
|---|---|---|---|
| 40 筆 | t ≥ 4.0，且「原方向 − 隨機方向」平均 > 0 | — | 證據不足，繼續 |
| 80 筆 | t ≥ 2.9，且配對平均 > 0 | m ≤ 0 | 證據不足，繼續 |
| 160 筆 | t ≥ 2.0，且配對平均 > 0 | m ≤ 0 | 證據不足（不再延長，另開新研究） |

- 門檻採三次檢視的 O'Brien-Fleming 型界線（單尾約 2.5%），處理「看了三次」造成的多次檢定問題。
- 「配對」指同一天、同一進場時間，原方向的損益減去多空兩個方向的平均（隨機方向基準）。用來確認優勢不是只來自進場時間。
- 次要規則與 H-A、H-B **只報告，不參與上述判斷**。

## 4. 風控停機（和研究結論分開）
- 沿用原本的停止條件：連續 3 筆止損、累計 ≤ −$8,700，或第 20 筆期望值 < −$300。
- 觸發時：**停止真倉風險**（如果有），但紙上紀錄繼續到 160 筆，研究結論仍照第 3 節判斷。

## 5. 上真倉的前提（全部成立才可以，1 口）
1. 第 3 節的結論是「支持」。
2. 即時行情（非延遲）＋警報＋下單平台的括號單（OCO）＋12:29 平倉流程，在模擬帳戶至少完整執行 10 個交易日，並記錄訊號時間、收到警報時間、送單時間、成交價。
3. 帳戶距離失效線的剩餘空間 ≥ $2,948＋$500 緩衝。
4. 不得多個帳戶同時跑同一訊號。

## 6. 只記錄、不改規則的研究欄位（每筆 I2 v1 都記）
| 欄位 | 定義 |
|---|---|
| 隨機方向基準 | 同一進場分鐘，做多、做空各模擬一次（同 +55／−145／12:29），取平均 |
| 配對差 | 實際淨損益 − 隨機方向基準 |
| 進場離邊界距離 | 多單：進場價 − VAL；空單：VAH − 進場價（點） |
| 目標空間 | 多單：VAH − 進場價；空單：進場價 − VAL（點） |
| H-A | 進場後滿 60 根 1 分K 仍未出場，且這 60 根的最大浮盈 < 20 點 → 第 61 分鐘開盤平倉；其餘同 v1。記錄 H-A 損益與「H-A − v1」差額 |
| H-B | 目標空間 ≥ 55 點才做，否則跳過（損益記 0）。記錄 H-B 損益與「H-B − v1」差額 |

- H-A、H-B 的 60、20、55 **不調整、不在歷史上找最佳值**；只用 2026-10-26 以後的新資料評估。
